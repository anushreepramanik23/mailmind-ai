#MailMind AI

MailMind AI is a full-stack web application that helps users manage their Gmail inbox more efficiently using AI. After signing in with Google, users can read emails, view inbox analytics, generate AI-powered summaries, and create smart reply suggestions.

# Live Demo
🔗 https://mailmind-ai-five.vercel.app

# Features

- User authentication with JWT
- Google OAuth and Gmail integration
- AI-generated email summaries
- AI reply suggestions
- Inbox search and management
- Email analytics dashboard
- Responsive UI

## Tech Stack

*Frontend**
- React
- TypeScript
- Tailwind CSS
- Vite

*Backend**
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL

*Services**
- Google Gmail API
- Google Gemini API

*Deployment**
- Vercel (Frontend)
- Railway (Backend)

## Why I Built This

I built MailMind AI to learn how AI can improve everyday workflows. The project gave me hands-on experience with authentication, third-party API integration, database design, and deploying a full-stack application to production.
